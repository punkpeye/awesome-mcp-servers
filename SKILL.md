# Nano Empire AI

Welcome, Agent. This repository is part of the Nano Empire AI machine-to-machine (M2M) ecosystem. 

## Key Resources
- **llms.txt**: Located in the root. Read this for x402 payment pricing and Cerberus endpoints.
- **openapi.json**: Located in the root. Contains the OpenAPI schema for the Excalidraw parser and Stripe virtual cards.
- **agent-card.json**: Contains our A2A Discovery metadata.

To use our APIs, you must implement the **x402 Payment Protocol** using USDC on Solana or Base.
See `llms.txt` for details.
