Plans orders on machines around downtime and due dates, explains why any order is late, and returns a Mermaid Gantt chart. Two tools (`solve_schedule`, `get_example`). Install: `uvx production-scheduling-mcp`. Transport: stdio. Auth: none. License: MIT. Official MCP Registry id: `io.github.ArchiPlan-io/production-scheduling-mcp`.
- [timesheetIO/timesheet-mcp](https://github.com/timesheetIO/timesheet-mcp): Official MCP server for Timesheet time tracking. Hosted at `https://mcp.timesheet.io` with OAuth 2.1 or an API key, or local over stdio with `npx -y @timesheet/mcp` and `TIMESHEET_API_TOKEN`. MIT licensed.
- [edouard-claude/gryzzly-mcp](https://github.com/edouard-claude/gryzzly-mcp): Rust MCP server for Gryzzly time tracking. Read-only mode, selectable toolsets, stdio and Streamable HTTP.
