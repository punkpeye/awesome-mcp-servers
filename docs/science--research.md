- [AgentFEM MCP](https://github.com/haoming-luo/agentfem-mcp): Create, validate and run inspectable finite-element projects, then retrieve numerical evidence through seven typed tools. Install: `python -m pip install agentfem-mcp`; launch: `agentfem-mcp`. Transport: `stdio`; no API key. Requires a separately installed compatible AgentFEM scientific runtime and an explicit project root via `AGENTFEM_MCP_ROOTS`. [Setup and client configurations](https://github.com/haoming-luo/agentfem-mcp#readme). License: Apache-2.0.

- [MakerSim (RawLabs/MakerSim)](https://github.com/RawLabs/MakerSim): Local Python MCP server and CLI for experimental load-path analysis of 3D-printed STL parts: multi-load tests, stress and movement fields, revision comparisons, mesh-refinement studies, PNG captures, visual reviews, and persistent design sessions with human pause/resume checkpoints. Install from the repository with Python 3.11+ and `uv sync`, then configure the absolute path to `.venv/bin/makersim-mcp`. Transport: `stdio`; no API key or hosted service required. Docs: [local agent setup](https://github.com/RawLabs/MakerSim#local-ai-agent-interface). License: [MIT](https://github.com/RawLabs/MakerSim/blob/main/LICENSE) for original software and documentation; logo/artwork reuse remains restricted. Results do not establish failure predictions or safe working loads.

Transport: `streamable-http`; no auth; read-only. Data CC BY-SA 4.0, code Apache-2.0. Source: https://github.com/ctrl-maud/slashyear. Official Registry: `com.slashyear/mcp`.
