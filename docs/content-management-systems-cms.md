## 📝 Content Management Systems

Servers specifically designed to interact with CMS platforms.

- [Blawgy](https://github.com/adamgusky/blawgy-mcp): Keyword research, then write and publish SEO blog posts to WordPress, Shopify, Webflow, Wix, Framer, Ghost or Duda from any MCP client. Hosted Streamable HTTP at `https://app.blawgy.com/mcp`; OAuth 2.1 with dynamic client registration or Bearer API key. [Docs](https://blawgy.com/mcp). Commercial service with a free trial; the listing repo is MIT.
- [Polyblog](https://github.com/polyblog-io/claude-plugin): Research topics, draft text and manage multilingual blog articles, localization coverage and editorial workflows with confirmed publication changes. Hosted Streamable HTTP at `https://mcp.polyblog.io/mcp`; OAuth account authorization required. [Docs](https://www.polyblog.io/developers/?utm_source=official-mcp-registry&utm_medium=mcp_directory&utm_campaign=mcp-registries-2026#mcp). Public connector configuration and workflow skills: Apache-2.0.
- [Tutorializer](https://github.com/tutorializer/claude-plugin): Audit localized product-tutorial libraries, rendered videos and voiceovers, and maintain tutorial definitions, projects and pronunciation rules with confirmed changes. Public connector configuration and workflow skills: Apache-2.0.
- [Total CMS](https://github.com/totalcms/cms): Flat-file PHP CMS with a built-in MCP server at `https://your-site/mcp` — no separate install. Agents discover collections and schemas, query and search content, and read version-matched docs; with a Pro license, OAuth or an admin API key unlocks content writes gated by access groups. Streamable HTTP; OAuth 2.1 or API key. [Docs](https://docs.totalcms.co/mcp/server). Commercial.
- [SlopIt](https://github.com/Simbastack-hq/SlopIt): Blog host built for AI agents. Every blog also serves llms.txt, a markdown twin of each post, RSS and a sitemap. Hosted Streamable HTTP at `https://slopit.io/mcp`; Bearer API key, or OAuth at `https://slopit.io/mcp/oauth`. [Docs](https://slopit.io/slopit.SKILL.md). Free plan; source is MIT and self-hostable.
