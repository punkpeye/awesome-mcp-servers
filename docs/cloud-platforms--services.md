## ☁️ Cloud Platforms & Services

Servers integrating with major cloud providers or specific cloud services.

- [Bastrio](https://github.com/cihalqe/bastrio): Hosted MCP for managing remote servers, SSH terminals, files, databases and proxies with scoped permissions and approval workflows. Connect to `https://bastr.io/api/mcp` using Streamable HTTP and OAuth, or a scoped Bearer API key. Requires a Bastrio account and an authorized workspace; pricing and quotas follow the account plan. No local installation is required. [Connection guide](https://bastr.io/mcp.html) · [Client configuration](https://github.com/cihalqe/bastrio/blob/main/docs/plugin-install.md). Official MCP Registry: `io.bastr/bastrio`.
- [LocalCloud MCP](https://github.com/LocalGCloud/localcloud-cli): Free local cloud environment for AI coding agents to build, test, and debug Google Cloud applications through discovery, SDK configuration, resource inspection, queries, and diagnostics. Requires Docker engine, LocalCloud CLI, and the LocalCloud Docker image; native macOS and Linux. Transport: stdio. Launch with `localcloud mcp`, or configure Cursor automatically with `lc mcp install --client cursor`. For manual JSON, use the absolute executable path from `command -v localcloud` and `args: ["mcp"]`; no remote endpoint or Google Cloud credentials are required for local workflows. [Website](https://local.cloud/) · [Setup guide](https://github.com/LocalGCloud/localcloud-cli#ai-agents--mcp).
- [agvps](https://agvps.shveik.dev): Servers for AI agents, rented by the month: a Linux server (Ubuntu 24.04) with root access and a public IPv4, in Germany or Finland. Streamable HTTP at `https://agvps.shveik.dev/mcp`; no API key or account, each call is paid with x402 or MPP stablecoins and a server is renewed by paying again; `initialize` and `tools/list` are open; hosted, closed source.

Proposes Asset Bundle diffs and SQL; never applies them. Transport: stdio. Install: `pip install -e ./mcp` then run `dbu-waste-finder-mcp`. - [Light Cloud MCP Server](https://github.com/light-cloud-com/mcp-server): Lets an agent sign up or sign in by device code and run apps on the Light Cloud hosting platform: deploy from GitHub or a local folder, manage environments, logs, metrics and rollbacks, Postgres/MySQL databases (schema, SQL, dump/import), custom domains, billing and members (about 110 tools). Install: `claude mcp add light-cloud -- npx @light-cloud/mcp-server`. Local stdio transport; TypeScript.
- [mrhy7176/cloudgpu-mcp](https://github.com/mrhy7176/cloudgpu-mcp): Rent a per-minute GPU on cloudgpu.app from an MCP client: list GPUs, get a quote, create an instance after the user confirms the quote, run commands, upload and download files, read logs and stop the instance.
- [VoltageGPU (vgpu mcp)](https://github.com/VoltageGPU/VOLTAGEGPU-CLI): List VoltageGPU offers, start an Intel TDX Confidential VM with an NVIDIA GPU with a required ttl and max_hourly_price, run commands and copy files over the user's local SSH key, verify the TDX quote and GPU attestation on the user's machine, call confidential models on an OpenAI-compatible API, and release machines (rm needs confirm=true).
- [NetActuate](https://netactuate.com/mcp): Answers from NetActuate's own published data: data centers and specs, compliance by site, internet exchanges, products and pricing, marketplace apps, docs and API, each linked to its source page. NetActuate is a global edge infrastructure and BGP anycast provider. The server lets an agent find NetActuate's sites nearest a city, which sites hold a certification (SOC 2, HIPAA, PCI-DSS, ISO 27001), the internet exchanges it peers at, its products and published pricing, apps from its deployment marketplace with their VM sizing, and its technical docs and API reference. Read-only: 13 tools, all annotated readOnlyHint, no write path.
- [FFxF (net.ffxf/cloud)](https://ffxf.net/agents): Official remote MCP server for FFxF, a cloud provider in Montréal, Canada. An agent can rent and manage KVM virtual machines, managed databases (PostgreSQL, MySQL, MariaDB, Valkey), private networks, firewalls and load balancers, billed by the hour in CAD. 71 tools, each mapped to one endpoint of the public API and to the scope it needs, so the API key decides what the agent may do. Catalogue tools (plans, images) answer without a key. Listed in the official MCP registry as `net.ffxf/cloud`. Endpoint: `https://ffxf.net/mcp`; transport: streamable-http; auth: bearer. License: Proprietary (hosted service).
- [Nodo](https://nodo.com): Hosted MCP server that gives an agent a cloud Linux machine with a shell and a Chrome browser that keeps its logins between runs, plus an optional Android phone. The agent builds workflows there that run on a schedule after the chat closes, and steps such as sending or posting can pause for the user's approval. Tools include `get_workspace_context`, `list_templates`, `create_draft`, `validate_draft`, `run_workflow`, `set_workflow_schedule` and `get_run_events`. Transport: Streamable HTTP. Endpoint: `https://mcp.nodo.com/api/user/mcp`. Auth: OAuth sign-in in the browser; a Nodo workspace is created at first sign-in. Install: `claude mcp add --transport http nodo https://mcp.nodo.com/api/user/mcp`. Clients: Claude Code. Setup: https://nodo.com/setup. Proprietary hosted service; new workspaces get 500 trial credits for 14 days.
