Free for 3 apps and 10,000 calls a month; Pro is $29 a month.
- [Agency Check](https://github.com/CyberStrategy1/agency-check): Get a second look before it acts. Before an agent buys, sends, books, shares, signs up, or connects an app, it calls `agency_check` with what it is about to do. The server returns Ready, Pause, or Clarify with a plain-language reason (for example: the user named one recipient but the send goes to 214 people). Other tools: `describe_ruleset`,...
- [HANRIA Agent Mandate Check](https://hanria.ai/llms.txt): Before it sends, pays, deletes, publishes, installs or changes access, an agent passes the operator's written mandate and the proposed action to `check_action` and gets `permit`, `deny` or `escalate` with the governing clause, a reason and an action digest. A second tool, `validate_mandate`, checks a mandate before use. It is advisory: it cannot stop an action, and it keeps no request content. Treat an error as deny.
- [layervai/qurl-mcp](https://github.com/layervai/qurl-mcp): Share localhost web apps, private APIs, and selected files through expiring qURL access links: publish a running local app privately and issue a short-lived link, or create, list, extend and revoke qURLs, tokens and sessions with an API key. Install: `npx -y @layervai/qurl-mcp` (no-account mode needs the qURL CLI: see README). Env: `QURL_API_KEY` (optional). Remote: `https://mcp.connector.layerv.ai/mcp` with `Authorization: Bearer <qURL API key>`. Transport: stdio and streamable-http. Auth: api-key. Supported clients: Claude Desktop, Claude Code, Cursor, Codex. License: MIT.
