Hosted Streamable HTTP at `https://myspainvisa.com/api/mcp`; no auth, no account. Official MCP Registry id `com.myspainvisa/spain-visa`. Repo: https://github.com/gmdavid91/myspainvisa-mcp.
- [AwardClaw](https://www.awardclaw.com/agents): Business and first class award seat alerts, saver availability search, trip watches and points news. Tools: `search_drops`, `get_drop`, `search_award_space`, `list_trip_watches`, `create_trip_watch`, `delete_trip_watch`, `get_daily_briefing`, `search_points_news`, `get_card_offers`, `get_account`. Transport: Streamable HTTP at `https://www.awardclaw.com/api/mcp`. Auth: API key as a Bearer token in the Authorization header (keys from a Pro+ account at https://www.awardclaw.com/dashboard/agents). Official MCP Registry id `com.awardclaw/award-travel`.
- [FlightQueue](https://mcp.flightqueue.com): Live and predicted TSA/security wait times, FAA delays, EES border queues, lounges, terminals and airline baggage policies for 8,000+ airports. 22 tools (19 free, 3 premium). Hosted Streamable HTTP endpoint at `https://mcp.flightqueue.com/mcp`; OAuth 2.1 with PKCE, free account sign-up, no API key. [Product page](https://flightqueue.com/mcp).
- [SlickTrip](https://github.com/sliktrip/slicktrip-mcp): Get live flight, hotel and seat prices and set price alerts: search flights and hotels for real dates, see the cheapest days to travel on a price calendar, check which seats are still open on a flight, and watch any fare, stay, seat or flexible bucket list (SlickTrip emails or texts the traveler when the price drops). Booking happens on the airline's or hotel seller's own site. 38 tools. Category suggestion: Travel.
- [ATAbooking](https://atabooking.com/mcp/docs/): ATAbooking is agent-to-agent booking. A traveller asks their AI, such as Claude, ChatGPT (on plans that allow custom MCP servers) or another MCP client, for a stay. ATAbooking searches live availability and books directly with the hotel, and the guest pays the hotel. Hotels pay a flat 5% fee instead of the 15–20% the big booking sites take. Demo: sample hotels, no real bookings yet.
- [Stadiq](https://github.com/snenenenenenene/stadiq-mcp-server): Road works, De Lijn transit disruptions, air quality and briefings for any point in Flanders and Brussels. Four read-only tools: stadiq_locations, stadiq_disruptions, stadiq_air_quality, stadiq_briefing. Requires a free Stadiq API key from https://stadiq.app/developers. Install: `npx -y stadiq-mcp`. Also in the official MCP registry as `io.github.snenenenenenene/stadiq`.
