- [Kling AI Global Plugin](https://github.com/klingai-tech/claude-plugin): Official hosted MCP for image and video generation, reference-based workflows, reusable subjects, motion control and task tracking. Transport: Streamable HTTP. Endpoint: `https://kling.ai/mcp/plugin`. Auth: OAuth with a Global-region Kling account. Install: `claude mcp add --transport http kling-ai-global https://kling.ai/mcp/plugin`. Generation consumes account credits; Global and China accounts, credits and task IDs are separate. Available models and parameters depend on live tools and account permissions. Docs: https://kling.ai/app/mcp/guide. The repository is the client plugin and documentation, not the hosted server source; hosted-service terms apply. Claude Code plugin: `claude plugin marketplace add klingai-tech/claude-plugin`, then `claude plugin install kling-ai@klingai`. Gemini CLI: `gemini extensions install https://github.com/klingai-tech/claude-plugin`. Plugin bundle: [@klingai/plugin-global](https://www.npmjs.com/package/@klingai/plugin-global).
