## 🏗️ Build & Deployment Tools

Servers interacting with build systems, containerization, CI/CD, or deployment platforms.

- [Droply](https://droply.so): Lets an agent publish HTML pages, Markdown, CSV, SVG, multi-file websites and other files as shareable links at `https://<name>.droply.page`, update a project later without changing its link, list projects with view counts, rename a link, add or remove a password, hide a page from search engines, and take a project offline (restorable for 7 days). Tools: `publish`, `update_project`, `list_projects`, `get_project`, `update_project_settings`, `delete_project`. Transport: Streamable HTTP at `https://droply.so/mcp`. Auth: OAuth 2.1 with dynamic client registration, or a Droply API key as a bearer token. Free plan: 1 project. Docs: https://docs.droply.so/#mcp. Official MCP Registry: `so.droply/droply`.

Needs a macbox account ($0.05 per Mac minute). Install: `npx -y macbox mcp`. Stdio transport. Official MCP Registry id `io.github.opslane/macbox`. MIT.
